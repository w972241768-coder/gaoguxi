一、判定规则（先看口径，再看结论）

阈值来自 20 年含分红回测的四关稳健性检验：「收盘 < 周 MA60（线下即买）」B1 只过 2 关； 从 偏离 < −3% 起（B2）才四关全过，−5% / −8% / −10% / −15% 同样全过 ⇒ 越深越稳，但 −3% 是起步门槛。

① 定池优先

鳄鱼派内核：先用分红质量定池，再用周 K 60 线定买点。 待核区 / 池外观察 / 扫描层未通过分红质量，按策略不适用买点判定，本看板只覆盖主池子 17 只。

② TR 口径是前置条件

周线是不复权价，高股息股每年除息形成「假跌」。 先构造 TRt = TRt−1 × (sr×closet + dps) / closet−1， 周 MA60 = 60 周 TR 均值，偏离 = TR / MA60 − 1。除息跳空不再污染判定。

③ 三态输出

可进入＝买点成立且分红质量通过；观察·待核＝买点成立但质量为条件通过； 暂不进入＝偏离未达 −3%。收复均线只停止买入、不调出池子，暂不进入 ≠ 卖出。

派生计算

  • 分红调整 TR 序列 → 周 MA60 → 偏离 dev = TR/MA60 − 1
  • ROC60 / RSI(14 Wilder) / KDJ J / TTM 股息率均在 TR 上同源计算
  • 买点三态（成立 / 深档 / 不成立）+ 进入三态（可进入 / 观察 / 暂不进入）
  • 距 −3% 的偏离百分点差；加成项（深档 ≤−5%、TTM 票息 >5%）

研究判断

  • 「先用分红质量定池、再定买点」与四关结论一致，−3% 门槛不可放宽到「线下即买」
  • 旧口径 3 只伪买点源于除息假跌，属口径错误而非市场变化
  • TTM 股息率 >5% 在 20 年回测中最稳（t=3.59 / 52 周胜率 80%），本页只作加成项、不作硬门槛
  • 暂不进入 ≠ 卖出；按鳄鱼派，收复均线只停止买入、不调出池子
